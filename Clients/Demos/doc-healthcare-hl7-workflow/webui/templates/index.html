DatabaseSqlListener — SQL Server

  • Class: com.pilotfish.eip.modules.db.DatabaseSqlListener
  • JdbcDriver: $$sqlserver.driver = com.microsoft.sqlserver.jdbc.SQLServerDriver
  • JdbcURL: jdbc:sqlserver://sqlserver:1433;databaseName=DocHealthcare;...
  • Claims PENDING with UPDATE...OUTPUT → status becomes PROCESSED

Driver JAR

  • mssql-jdbc-12.8.1.jre11.jar in WEB-INF/lib
  • Seed data: transfers, bed assigns, housing MULTI packages (EventIds 1003+)

Expand MULTI

  • Same XSLT as Oracle route — e.g. TRANSFER,BED_ASSIGN → 2 events

Handoff

  • EIPTransport → Split And Generate HL7.Programmable (Trigger) Listener

DatabaseSqlListener — Oracle

  • Class: com.pilotfish.eip.modules.db.DatabaseSqlListener
  • JdbcDriver: $$oracle.driver = oracle.jdbc.OracleDriver
  • JdbcURL: jdbc:oracle:thin:@oracle:1521/XEPDB1
  • User: docoms / schema tables operational_events, patients
  • SQLXML: SELECT PENDING, then UPDATE to PROCESSED

Driver JAR

  • ojdbc11-21.9.0.0.jar in WEB-INF/lib
  • Seed data: admits, discharges, demo updates, OMS MULTI (EventIds 2001+)

Expand MULTI

  • e.g. ADMIT,BED_ASSIGN,DEMO_UPDATE → 3 forked HL7 messages

  • Same Route 2 listener as SQL Server — one HL7 pipeline for both DBs

TriggerableListener

  • Name: Split And Generate HL7.Programmable (Trigger) Listener
  • Receives expanded event batch from Route 1

FormatProfile “Split Events”

  • ForkModule: com.pilotfish.eip.modules.other.XPathForkingModule
  • ForkingXPath: //Event
  • One transaction per healthcare event (7 DB rows → 10 txs when MULTIs expand)

Post-fork attribute mapping

  • XPathEvaluator sets EventId, EventType, OffenderId
  • ADMIT→A01, TRANSFER/BED_ASSIGN→A02, DISCHARGE→A03, DEMO_UPDATE→A08
  • Must run on the target after fork so each file gets the right name

transform-event-to-hl7.xslt

  • Output method: text (pipe-delimited HL7 2.5.1)
  • Segments: MSH, EVN, PID, PV1, ZPF (PilotFish audit)
  • Sending app/facility: PILOTFISH|DOC → receiving MYAVATAR|NETSMART

DirectoryTransport

  • Directory: /opt/pilotfish/output/hl7
  • FileName: {EventId}_{EventType}_{Hl7Trigger}.hl7
  • Example: 1002-1_ADMIT_A01.hl7
