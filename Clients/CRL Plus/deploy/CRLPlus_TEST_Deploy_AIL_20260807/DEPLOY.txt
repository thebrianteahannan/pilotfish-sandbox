DEPLOY STEPS
------------
A) Copy interface files into TEST eip-root
   Preserve paths under the TEST eip-root:

     interfaces/Clients/interfaces/AmericanIncomeLife/
       → copy/overwrite entire folder from this package

     interfaces/Status/routes/4 - Route to client specific/route.xml
       → overwrite (keeps other clients; updates AIL ServiceName)

B) Merge environment properties
   Add/update keys from environment-settings-AIL-TEST.conf.snippet into the
   TEST eip-root environment-settings.conf (or host-specific props store):

     AILIncomingAuthFile=auth-test.txt
     AILOutgoingWsURL=…
     AILOutgoingWsUserName=…
     AILOutgoingWsPassword=…

   Outbound 1122 currently uses a sandbox placeholder URL. Leave as-is (or
   point at a mock) until AIL provides their status endpoint. Inbound 121
   does not depend on outbound working.

C) Restart eiPlatform / Tomcat on TEST
   So new routes, Status.4 wiring, and auth file are loaded.

D) Smoke test
   curl -u 'ail:AIL-TEST-qYTc-nc0N-6DUN' \
     -H 'Content-Type: text/xml' \
     --data-binary @sample-121.xml \
     "https://plus.intg.crlcorp.com/http-post/ail"

   Confirm:
     1) HTTP 200 / sync 121 response (not 401)
     2) Transaction archives under AIL
     3) Status.4 routes sourceClient=AIL to AIL 1122 Status


ROLLBACK
--------
  1. Restore backed-up AmericanIncomeLife folder (or delete new routes if none)
  2. Restore Status.4 route.xml
  3. Remove/revert AIL* props from environment-settings.conf
  4. Restart EIP
